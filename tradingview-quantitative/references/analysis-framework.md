# Shared Analysis Framework

1. State the question and decision it should inform.
2. Form testable hypotheses.
3. Select only the data needed to support or reject them.
4. Calculate comparable metrics over an explicit period.
5. Check results against another evidence type and identify conflicts.
6. Give a conclusion, confidence, and invalidation conditions.

Evidence levels:
- **Observed**: directly returned market, fundamental, calendar, or news data.
- **Derived**: calculations such as return, volatility, drawdown, breadth, valuation spread, or correlation.
- **Interpreted**: an explanation supported by observed and derived evidence.
- **Actionable condition**: a measurable future condition to monitor, not a prediction.

Confidence reflects evidence quality, agreement across data types, freshness, and sample size. Lower it for conflicts, missing data, or short samples.

Every formal report includes:
```text

Market/session:
Symbols and universe:
Historical window:
Data limitations:

```
