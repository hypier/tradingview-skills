# TradingView MCP Setup

This is a short setup guide so the research workflows can access current TradingView data. It intentionally does not document individual MCP tools or REST endpoints.

## Hosted connection

Use the hosted TradingView MCP server:

```text
https://mcp.tradingviewapi.com/mcp
```

Add it as an **HTTP/streamable HTTP MCP server** in the user's MCP client, then complete the TradingView Console sign-in or OAuth flow shown by that client. The one-click setup page is:

```text
https://www.tradingviewapi.com/mcp/
```

Do not put a TradingView Console API key directly into the hosted MCP URL. If the client cannot use OAuth, use the JWT configuration generated by the TradingView Console.

## Client checklist

1. Add the hosted URL as an MCP server.
2. Authenticate in the client or browser prompt.
3. Reload MCP or restart the client.
4. Confirm that tools whose names start with `tradingview_` are visible.
5. Run a small symbol search or quote request before starting a larger analysis.

If no `tradingview_*` tools appear, diagnose the MCP connection before attempting research. A local OpenAPI MCP wrapper exposes different REST-shaped tools and is not the hosted server expected by this skill.

## Client-specific help

For client-specific setup, use the MCP client's own server configuration UI. Keep this file focused on the hosted endpoint and connection test so it remains stable when client menus change.
